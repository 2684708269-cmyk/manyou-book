# 漫游簿 · 互动旅行地图

一个无需构建即可运行的网页原型：世界地图会以可旋转、可缩放的地球呈现，并加载 Natural Earth 的全球省/州级行政区边界。页面先用轻量边界快速显示，再在后台升级至覆盖 4,500 多个一级行政区的 10m 精细数据。

## 运行

推荐使用本地静态服务器（直接双击 `index.html` 也可以，但部分浏览器会限制网络资源）：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 已实现

- 地球投影、拖动旋转、滚轮缩放和世界视图复位
- 全球省、州、自治区级区块点击
- “想去 / 去过”两种点亮状态及筛选
- 地区搜索与定位
- 照片选择、预览和浏览器本地保存
- 邀请码复制与加入共同地图的演示流程
- 桌面端和移动端响应式布局

## 原型说明

当前版本不包含服务端。旅行记录保存在浏览器的 `localStorage` 中；邀请码加入是完整 UI 流程的演示。要实现多人实时共享，需要接入登录、对象存储和数据库服务。

地图渲染库与行政区数据通过 CDN 加载，因此首次打开需要联网。
